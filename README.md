# TITAN AURA — Proof of Existence & Functionality

**Logica · Ascolto · Armonia**

TITAN AURA is an experimental computational research project at TITAN Research Labs, directed by Randy Rafael Moreta Ortiz. Its central question is how to reconstruct and check the path from initial information, through the transformations it undergoes, to the result it supports.

**INIZIO → MEZZO → FINE**

- **INIZIO — Starting information.** What was available at the outset, where did it come from, and what was missing?
- **MEZZO — Transformations.** Which observations were used, what was done with them, and can those steps be checked?
- **FINE — Result.** Which conclusion does the evidence support, and which questions remain open?

In limited studies with structured information, the working prototype has checked whether sources fit a request, recovered missing observations from authorized sources and kept a record of its decisions. It has also stopped when it could not determine what a request asked it to measure. Autonomous transfer to unfamiliar domains remains unconfirmed.

The laboratory uses different subject areas as evaluation material. Each case tests how far the prototype can follow the path from evidence to result. [Observed functionality and limits](FUNCTIONALITY.md) · [Project notice](NOTICE.md)
